# ⚡ Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SurajRawatr07/SURAJ-RWT-PORTFOLIO-2026.git
```

## 2️⃣ Go To Project Folder

```bash
cd SURAJ-RWT-PORTFOLIO-2026
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```
